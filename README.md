# 🎭 CraftyChat

**Локальное веб-приложение для ролевых игр (RP) с ИИ**  
*(без API-ключей, всё через копипаст из браузерных версий ChatGPT/Gemini)*

CraftyChat — это ваш личный «движок» для общения с AI-персонажами. Вы вручную копируете сгенерированный промпт из приложения, вставляете его в браузерную версию нейросети, получаете ответ и копируете его обратно. Приложение автоматически управляет контекстом, историей, лорбуками, саммари и пресетами, предоставляя интерфейс, похожий на SillyTavern, но без прямой интеграции с API.

---

## ✨ Основные возможности

- **Управление персонажами (ботами)** — карточки с полями (характер, внешность, речь, род деятельности, доп. информация), аватарки, привязка лорбуков.
- **Управление персонами (юзерами)** — своё описание, аватарка, возможность привязки к конкретному персонажу для автоматического выбора в чате.
- **Лорбуки (World Info)** — миры с записями, ключевыми словами, приоритетом (1–10), глубиной сканирования (0–100%) и статусами (постоянная / обычная / векторная). Записи автоматически активируются при совпадении ключевых слов в истории или текущем сообщении.
- **Чаты** — полноценный мессенджер с переключением режимов `User` / `Char`, отправкой сообщений, редактированием, удалением (с каскадной очисткой саммари), чекпоинтами, импортом/экспортом в JSON/TXT.
- **Главный промпт** — автоматическая сборка по алгоритму: `[Role] → [Presets] → [Character] → [User] → [Lore] → [Summary] → [Context] → текущее сообщение`. При превышении лимита токенов (настраивается от 5K до 100K) происходит обрезка: сначала урезаются векторные записи лорбука, затем удаляются самые старые блоки саммари.
- **Саммари (долгосрочная память)** — отдельный механизм, позволяющий создавать блоки пересказа по 10 сообщений. Помогает ИИ помнить события за пределами контекстного окна.
- **Пресеты** — коллекции с основным и дополнительным промптами, а также мини-пресетами (включаемыми/отключаемыми). Ползунок для задания максимальной длины промпта.
- **Фоны** — загрузка своих изображений, выбор из миниатюр, сброс к стандартному.
- **Импорт / экспорт** всех сущностей (персонажей, персон, лорбуков, пресетов, чатов) в формате JSON.
- **Подсчёт токенов** — через `tiktoken` (модель `gpt-4`), с fallback на приблизительный расчёт (1 токен ≈ 3 символа для русского текста).

## 🚀 Установка и запуск

### 1. Скачайте или клонируйте репозиторий

```bash
git clone https://github.com/your-username/craftychat.git
cd craftychat
```

### 2. Запустите одной командой

**Linux / macOS**
```bash
chmod +x start.sh
./start.sh
```

**Windows**
```bat
start.bat
```

Скрипт автоматически:
- создаст виртуальное окружение в `backend/venv` (если его нет);
- установит все зависимости из `backend/requirements.txt`;
- запустит Flask-сервер на `http://localhost:5000`.

После запуска откройте браузер и перейдите по адресу **http://localhost:5000** — перед вами интерфейс приложения.

> **Примечание:** при первом запуске может потребоваться время на установку `tiktoken` и `Pillow`. Это нормально.

### 3. Ручной запуск (без скрипта)

```bash
cd backend
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## 📖 Краткое руководство по использованию

### Начало работы
1. **Создайте персонажа** (кнопка `🤖 Персонажи` → `Создать`). Заполните поля (характер, внешность и т.д.) и сохраните.
2. **Создайте персону** (кнопка `👤 Персоны` → `Создать`). Это ваш игровой образ.
3. **Привяжите персону** к персонажу (в карточке персоны нажмите `➕ Привязать` и выберите персонажа) – тогда при открытии чата эта персона будет использоваться автоматически.
4. **Перейдите в чат** – кликните на персонажа в списке (или на его карточке) и выберите «Открыть чат».

### Работа с лорбуками
- Создайте мир (`📖 Лорбуки` → `Создать мир`).
- Добавляйте записи. Для каждой записи укажите:
  - **Ключевые слова** – при совпадении в истории запись активируется.
  - **Приоритет** (1 – самый высокий) – определяет порядок в промпте.
  - **Глубина сканирования** (0–100%) – какую часть истории проверять на ключевые слова.
  - **Статус**:
    - *Постоянная* – всегда включается в промпт (глубина игнорируется).
    - *Обычная* – активируется по ключевым словам.
    - *Векторная* – добавляется в конце блока лорбуков и обрезается до заданного лимита (по умолчанию 3000 символов).

### Генерация главного промпта
- Отправьте сообщение от **User** (режим должен быть `User`) – промпт автоматически соберётся, скопируется в буфер обмена и отобразится в консоли сервера.
- Вы также можете нажать `⚡ Сгенерировать промпт` в меню чата, чтобы повторить генерацию для последнего сообщения.
- Если в чате последний ответ был от бота (Char), генерация недоступна – сначала ответьте от User.

### Саммари (долгосрочная память)
- Откройте вкладку `📝 Саммари` (доступна только при открытом чате).
- Нажмите `⚡ Сделать текущий саммари` – система возьмёт первые 10 непересказанных сообщений, сформирует промпт для ИИ и скопирует его в буфер.
- Вставьте промпт в браузерный ИИ, получите пересказ, вставьте его в поле и сохраните блок.
- Блоки автоматически удаляются, если их диапазон затронут удалёнными сообщениями.

### Управление чатом
- В меню чата (кнопка `☰`) доступны:
  - закрыть чат,
  - список всех чатов этого персонажа,
  - новый чат,
  - чекпоинт (копия чата с текущей историей),
  - удаление сообщений (выберите индексы через запятую),
  - генерация промпта,
  - переключение режимов `User` / `Char`.

### Импорт / экспорт
Все сущности можно экспортировать и импортировать в формате JSON через соответствующие кнопки в каждом разделе. Это позволяет переносить данные между установками или делиться с другими пользователями.

## 🔌 API (кратко)

Полный список эндпоинтов описан в `backend/README.md`. Основные группы:

- `/api/presets` — пресеты и коллекции
- `/api/characters` — персонажи (Bot)
- `/api/personas` — персоны (User)
- `/api/lorebooks` — лорбуки и записи
- `/api/chats` — чаты, сообщения, саммари
- `/api/background` — фоны
- `/api/settings` — глобальные настройки

Все эндпоинты возвращают JSON, поддерживают методы GET, POST, PUT, DELETE.
